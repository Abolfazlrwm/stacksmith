THE PRODUCT
docubot — the middle ground.

Upload PDFs, Markdown, and plain-text documents, then ask questions of them in a chat interface. Answers are grounded in your own documents via retrieval-augmented generation (RAG) over a pgvector index — the model cites the source passage for each answer.

THE PRODUCT
  • The only outbound call from the host is the LLM completion; documents never leave the machine.
  • pgvector stores vectors inside Postgres, avoiding a separate vector database to run and back up.
  • RAG answers cite the source passage, keeping responses grounded and auditable.
  • Model-agnostic: works with OpenAI, Anthropic, or a local model.
